TERMS
TERMS / PUBLIC VALIDATOR

Diagnosis is evidence, not a guarantee.

HTML&HTML reports conditions measured on publicly reachable web surfaces. A score or finding does not guarantee search ranking, traffic, sales, AI citations, regulatory compliance or security.

USE BOUNDARY

Use the validator as a bounded diagnostic tool.

The service is designed for public websites and reversible technical decision support, not intrusive testing or access to protected systems.

PUBLIC TARGETS

Only public HTTP/HTTPS

Do not attempt to use the service to access private networks, localhost, protected resources or systems you are not authorized to assess.

NO GUARANTEE

Scores describe measured checks

100/100 means the measured rules passed at scan time. It does not represent a promise of rankings, visibility, revenue, security or third-party behavior.

PROPOSALS

Status remains explicit

Emerging mechanisms such as llms.txt, A2A and MCP are not represented as mandatory ranking requirements. Their source class and maturity must remain visible.

IMPLEMENTATION

Source context controls precision

Public scans do not know the internal source file that owns an observed behavior. File-level changes require codebase verification before implementation.

PAID SERVICE

Entitlement must be active

The paid mandate endpoint is fail-closed. If payment/entitlement infrastructure is not configured, no paid implementation output should be treated as purchased or activated.

RESPONSIBLE USE

No abuse

Do not automate abusive request volumes, evade network boundaries, submit secrets or use the service to interfere with third-party systems.

Kullanım sınırları

HTML&HTML skoru, yalnızca tarama anında ölçülen kontrolleri ifade eder; sıralama, trafik, satış, AI atfı, mevzuat uyumu veya güvenlik garantisi değildir. Sistem yalnızca herkese açık web yüzeylerinin teknik teşhisi için kullanılmalıdır; private ağlara, korumalı sistemlere veya yetkisiz hedeflere erişim amacıyla kullanılamaz.
