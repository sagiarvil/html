# Commercial Product Contract

## Free — USD 0

The user sees every public finding:

- issue ID
- category
- severity
- confidence
- evidence class
- affected public URL
- measured evidence
- category and overall scores
- crawler policy matrix
- formal llms.txt v2 audit trail

The free response does not hide defects to force checkout.

## Full Site Fix Mandate — USD 149

One domain / one engagement. The paid product unlocks implementation engineering:

- P0–P3 dependency order
- ROOT FIX
- RECOVERY
- PREVENTION
- acceptance/falsification test
- regression considerations
- stop/failure conditions
- rollback
- one re-scan within 30 days in the commercial scope

## Source-code boundary

Public observation can prove behavior but cannot reliably identify a source file. File/component targeting is allowed only after source/codebase ownership is established. A mandate must never invent a path to create false implementation precision.
