# Quick Start

1. Serve the repository with any static HTTP server, for example `npx serve .`.
2. Open `/` for the catalog.
3. Open `/live-preview.html?template=ledger` to test the responsive preview shell.
4. Edit storefront content in `index.html`.
5. Edit global design tokens and layout rules in `assets/css/main.css`.
6. Edit individual template demos in `demos/`.
7. Do not enable checkout until a real payment provider and final license terms are configured.
