# Product Scope

HTML&HTML measures externally verifiable website behavior and produces evidence-backed findings.

It does not claim:

- guaranteed Google ranking,
- guaranteed AI citations,
- guaranteed traffic or revenue,
- full WCAG certification from automation alone,
- security certification from header checks alone,
- field Core Web Vitals without relevant evidence,
- source-file ownership without codebase context,
- predictive link-rot probability without longitudinal data.

These boundaries are part of product quality, not disclaimers to be hidden from users.
