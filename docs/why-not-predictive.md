# Predictive Features Data Gate

Predictive link rot, industry percentiles and similar outputs are intentionally not enabled in the current engine.

They become eligible only when the system has:

- sufficient longitudinal observations,
- a defined sampling population,
- calibration and false-positive measurement,
- reproducible evaluation data,
- a user-visible confidence interval or uncertainty model.

Until then, current-state HTTP evidence is reported instead of invented predictive certainty.
