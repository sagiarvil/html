# HTML&HTML Preview Presentation Standard

The catalog preview, live demo, and delivered template must represent the same visual product.

## Rules

1. Catalog cards show the real rendered top viewport of the product, not a wireframe or placeholder illustration.
2. Live Demo opens the same HTML/CSS/JS source in a larger iframe with Desktop, Tablet, Tablet Portrait, and Mobile viewport controls.
3. Product details describe only capabilities visible in the delivered source or supported by evidence.
4. Every product demo must include a complete visual first impression: navigation, hero, primary CTA, product/service proof, and at least one meaningful downstream section.
5. Vertical products must be visually distinct. A category cannot be represented by the same generic layout with only color changes.
6. Demo-only assets or placeholders must be disclosed and must not be presented as included licensed production assets unless they are actually included.
7. No catalog thumbnail may claim a visual result the delivered template cannot reproduce.

Reference behavior: established premium HTML template catalogs commonly use product-specific visual previews in the catalog and a dedicated preview page with device controls and a real iframe. HTML&HTML follows the same buyer-clarity principle with original code, original product names, and original visual compositions.
