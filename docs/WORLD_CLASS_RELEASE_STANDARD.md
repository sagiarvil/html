# HTML&HTML World-Class Release Standard

A product is not sellable because its HTML renders. It is sellable only when a buyer can understand, inspect and desire the finished result before purchase.

## Release rule

A template may be shown as PURCHASE READY only when all of the following are true:

1. The live demo looks like a complete real website, not a component exercise or wireframe.
2. The visual identity is specific to the vertical and cannot be reproduced by recoloring another template.
3. The first viewport establishes brand, product, audience and primary action without explanatory marketplace copy.
4. The demo contains real page depth: navigation, content hierarchy, proof, conversion, footer and meaningful secondary pages where the vertical requires them.
5. Photography/media hierarchy is art-directed. Demo-only media is disclosed and is not represented as packaged production assets.
6. The product detail page states exact pages, files, behavior, dependencies, browser target, customization method, integration boundaries and exclusions.
7. Desktop, tablet and mobile previews represent the same delivered source.
8. Navigation, filters, forms, accordions, tabs, menus and other advertised front-end interactions actually work.
9. Accessibility, console, links/assets and responsive checks pass the available automated gates.
10. Claims are evidence-backed. If visual/browser/performance verification is incomplete, the product remains VERIFICATION PENDING.

## Visual bar

The reference bar is the best current premium HTML market, not the average low-cost template. Products should demonstrate editorial typography, strong image direction, disciplined spacing, convincing content density, refined micro-interactions and a complete vertical-specific story.

## Catalog rule

Do not compensate for weak products with quantity. One flagship product at release quality is preferable to ten generic demos. Products that have not passed the release bar stay visible only as upcoming concepts and cannot use a purchase-ready CTA.
