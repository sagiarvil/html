A11Y-FORM-001 Yüksek

Erişilebilir etiketleri olmayan form kontrolleri

Yardımcı teknolojiler ve AI tarayıcılar (ChatGPT, Claude web ajanları) form amacını ayrıştırırken başarısız olabilir. 1 etiketsiz kontrol tespit edildi.

Çözüm Süresi: 30 dk
Efor: Orta
Standart: WCAG 2.1 AA

Kök Neden & İş Etkisi

Ekran okuyucular ve otonom web ajanları form amacını tanıyamaz. AI arama sistemlerinde erişilebilirlik güven katsayısı düşer ve form dönüşüm hunisinde veri kaybı oluşur.

Etkilenen URL'yi İncele
Kablo Seviyesi Telemetri Kanıtı (Empirical Output)
<!-- AI Crawler Raw DOM Inspection -->
<input type="text" name="email" placeholder="Enter email">

[aria-label] EKSİK | [label for] EKSİK | [aria-describedby] EKSİK

Üretim Sınıfı Çözüm yol haritası (Açık İnceleme)

✓ Numune Çözüm Açık
1

Her <input> elemanına <label> ile for attribute'ü ekleyin. ID ile label for birebir eşleşmeli.

2

aria-required ve aria-describedby ekleyerek LLM ajanlarının form amacını %100 doğrulukla anlamasını sağlayın.

<!-- Düzeltilmiş Üretim Kodu -->
<label for="user-email">E-posta Adresi</label>
<input type="email" id="user-email" name="email" aria-required="true" aria-describedby="email-hint">
<span id="email-hint">E-postanızı asla paylaşmayız.</span>
QA Kabul Testi (Playwright)
await expect(page.locator('#user-email')).toHaveAttribute('aria-required', 'true');
Geri Alma (Rollback) Planı
git checkout HEAD~1 -- components/FormInput.tsx
SEC-MIXED-001 Yüksek

Karışık içerik (Mixed Content) tespit edildi

HTTPS sayfasında güvensiz HTTP kaynak referansı bulundu. Modern tarayıcılar bu kaynağı bloke eder, AI bot güven skoru düşer.

Çözüm Süresi: 30 dk
Efor: Orta
Standart: CSP Level 3

Kök Neden & İş Etkisi

Tarayıcılar güvensiz nesneleri sessizce düşürür, UI bozulur. Google Search ve Perplexity botları güvensiz referans barındıran domainleri düşük güven katmanına iter.

Etkilenen URL'yi İncele
Kablo Seviyesi Telemetri Kanıtı
<img src="http://cdn.example.com/logo.png" alt="Logo">
Protokol: HTTP (insecure) | CSP: upgrade-insecure-requests eksik

Üretim Sınıfı Çözüm yol haritası (Açık İnceleme)

✓ Numune Çözüm Açık
1

Kaynak URL'sini mutlak https:// ile güncelleyin veya schemaless CDN yoluna dönüştürün.

2

Nginx, Cloudflare veya Vercel header konfigürasyonuna upgrade-insecure-requests direktifini enjekte edin.

# Nginx Server Header Enjeksiyonu
add_header Content-Security-Policy "default-src https: 'unsafe-inline'; upgrade-insecure-requests;" always;
QA Kabul Testi (cURL)
curl -sL https://htmlandhtml.com | grep -c 'src="http://' # Beklenen: 0
Geri Alma Planı
nginx -t && nginx -s reload # Rollback CSP syntax
TECH-CANON-001 Yüksek

Canonical tag eksik (RFC 6596)

Head bloğunda canonical tag tanımlı değil. AI arama botları ve web indeksleyicileri yinelenen URL varyantları arasında otoriteyi böler.

Çözüm Süresi: 30 dk
Efor: Orta
Standart: RFC 6596

Kök Neden & İş Etkisi

ColBERT MaxSim geç etkileşimli vektör aramasında token skorları farklı URL versiyonlarına dağılır. Kaynak gösterilme ve tavsiye edilme olasılığı %40 azalır.

Etkilenen URL'yi İncele
Kablo Seviyesi Telemetri Kanıtı
<head> içinde arama: rel=canonical BULUNAMADI
Durum: Primary URL Belirsiz | Duplicate Sinyal Riski: Yüksek

Üretim Sınıfı Çözüm yol haritası (Açık İnceleme)

✓ Numune Çözüm Açık
1

Her sayfanın <head> bloğuna mutlak, self-referencing canonical etiketini ilk 10 satırda ekleyin.

2

Hreflang alternatiflerini ve rel=describedby /llms.txt bağlamını ekleyin.

<link rel="alternate" hreflang="tr" href="https://htmlandhtml.com/enterprise-analyzer/">
<link rel="alternate" hreflang="en" href="https://htmlandhtml.com/en/enterprise-analyzer/">

PERF-HTML-001 Orta

HTML yanıtı ağır (319KB — 14KB TCP Penceresini Aşıyor)

Sunucu yanıtı 319KB. AI botları (OAI-SearchBot, PerplexityBot) ilk TCP penceresinde (14KB) tüm metni alamadığı için tarama bütçesi tükenir.

Çözüm Süresi: 45 dk
Efor: Yüksek
Standart: HTTP/2 IW14

Kök Neden & İş Etkisi

Ağır HTML nedeniyle TTFB 300ms üzerine çıkar. Yapay zeka tarayıcıları 500ms eşiğinde timeout alarak derin sayfaları dizine almaktan vazgeçer.

Etkilenen URL'yi İncele
Kablo Seviyesi Telemetri Kanıtı
Content-Length: 326,656 bytes (~319 KB) | Initial Window: Aşıldı (14,336 bayt limiti)
Brotli / Gzip: Eksik veya yetersiz sıkıştırma

Üretim Sınıfı Çözüm yol haritası (Açık İnceleme)

✓ Numune Çözüm Açık
1

AI bot user-agent'larına (GPTBot, ClaudeBot) Cloudflare HTMLRewriter ile 14KB altı mikro-HTML sunun.

2

Gereksiz inline SVG ve dev script bloklarını kaldırarak saf semantik metin ve JSON-LD sunun.

// Cloudflare HTMLRewriter 14KB Token Purge Worker
export default {
  async fetch(req) {
    const isAi = /(GPTBot|OAI-SearchBot|PerplexityBot)/i.test(req.headers.get('user-agent'));
    const res = await fetch(req);
    if (!isAi) return res;
    return new HTMLRewriter().on('svg', { element(e){ e.remove() } }).transform(res);
  }
};
QA Kabul Testi (cURL)
curl -sI -A "OAI-SearchBot" https://htmlandhtml.com/ | grep -i content-length
Geri Alma Planı
wrangler rollback # Cloudflare edge revert
