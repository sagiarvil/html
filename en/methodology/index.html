PUBLIC METHODOLOGY

Every score needs a traceable reason.

Standards, vendor guidance, proposals, direct measurement and internal heuristics are not presented as equivalent. Unavailable evidence is not forced into pass or fail.

OFFICIAL_STANDARD

Normative standard

Formal protocol or platform standard.

OFFICIAL_VENDOR

First-party vendor guidance

Current documentation from the relevant product or crawler operator.

PROPOSAL

Emerging proposal

A useful convention such as llms.txt that is not a mandatory web standard.

MEASURED

Direct measurement

HTTP / HTML / header / robots / link evidence.

INTERNAL_HEURISTIC

Product heuristic

Decision-support rule without normative-force claims.

EXPERIMENTAL

Experimental surface

Low-adoption or early agent signal.

SCORING

UNKNOWN is not failure. It is not success either.

If reliable evidence is unavailable, the rule is excluded from the denominator. Core Web Vitals remain NOT_MEASURED without field/lab data.

SAFETY

SSRF fail-closed

Private/local/reserved targets, credential-bearing URLs, non-standard ports and redirect pivots into private address space are rejected.
