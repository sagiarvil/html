GOVERNANCE & METHODOLOGY

Scoring Methodology & Governance Standards

How HTML&HTML measures 12 independent diagnostic categories, assigns evidence classes, handles unmeasured signals, and enforces deterministic scoring boundaries.

EVIDENCE CLASSES

Six-tier evidence hierarchy.

We never conflate an official standard, a vendor guideline, an evolving proposal, and an internal heuristic.

OFFICIAL_STANDARD

OFFICIAL_STANDARD

RFCs (e.g. RFC 9309 robots.txt), W3C standards, Schema.org official vocabularies.

OFFICIAL_VENDOR

OFFICIAL_VENDOR

Published vendor crawler documentation from OpenAI, Anthropic, Google, and Perplexity.

PROPOSAL

PROPOSAL

Emerging specifications such as llms.txt v2. Evaluated with limited weight and marked as evolving.

MEASURED

MEASURED

Directly observed HTTP responses, status codes, headers, and SSL parameters.

INTERNAL_HEURISTIC

INTERNAL_HEURISTIC

Internal algorithmic patterns detecting dead-end navigation or anti-patterns.

EXPERIMENTAL

EXPERIMENTAL

Early-stage agent discovery signals (e.g. MCP endpoints), labeled separately without score inflation.

EPISTEMIC HONESTY

Unmeasured signals: The NOT_MEASURED contract.

Core Web Vitals cannot be fabricated from raw HTML fetches. Without real user CrUX metrics, performance hygiene strictly reports NOT_MEASURED.

SSRF GUARD

Private IPv4/IPv6 ranges, loopback addresses, and cloud metadata endpoints fail closed before any TCP handshake to prevent SSRF vulnerabilities.
