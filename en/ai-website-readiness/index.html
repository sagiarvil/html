HTML&HTML / MODEL

12 engines. Four decision layers.

The engines are not a random checklist. They are grouped around access, understanding, trust and action.

A / ACCESS

Access

Crawl & Index, AI/GEO Access and Link Integrity measure whether a crawler, agent or user can actually reach the resource.

B / UNDERSTANDING

Understanding

Technical SEO, llms.txt v2, Structured Data and Agent Readiness measure signals that help machines understand site structure and content.

C / TRUST

Trust

Security, Content Trust, Accessibility and Performance Hygiene remain separate signals rather than being collapsed into a vague quality score.

D / ACTION

Action

Conversion and agent-ready surfaces evaluate whether the next step is visible and safely actionable.
