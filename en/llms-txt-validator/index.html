FAQ

Frequently Asked Questions

What is the difference between llms.txt and llms-full.txt?

llms.txt serves as a concise directory of curated markdown links, while llms-full.txt contains the aggregated full text of documentation for direct model ingestion.

How should llms.txt be discovered?

Through root placement (/llms.txt) and via rel='describedby' Link headers or link elements on key HTML pages.

Why did my llms.txt fail validation?

Common causes include missing H1, missing blockquote summary, unbulleted link entries, or linked URLs returning 404/500 errors.
