AI MARKA GÖRÜNÜRLÜK TAKİBİ / ÜCRETLİ MODÜL

AI yanıtlarında markanız gerçekten geçiyor mu?

OpenAI Responses API + web araması, Perplexity Sonar ve Gemini + Google Search temellendirme yüzeylerinde tarafsız sorguları çalıştırır; marka anılması, alan adı kaynak gösterimi ve kullanılan kaynak URL’lerini ayrı ölçer. Tüketici ChatGPT/Perplexity/Gemini arayüzleri birebir aynı sonuçları vermeyebilir.

AI görünürlüğünü kanıtla

Marka/alan adı yalnızca sonuçta aranır. Ölçüm sorgularına marka veya alan adı yazılması engellenir; aksi halde sonuç yapay biçimde yükselir.

Erişim anahtarı tarayıcıda kalıcı saklanmaz. Sağlayıcı API anahtarları yalnızca sunucu tarafında tutulur.
ÖLÇÜM SÖZLEŞMESİ

Markayı isteme yazıp yapay “anılma” üretmiyoruz.

Takip modülünün temel kuralı tarafsız sorgudur. Hedef marka veya alan adı sorguda geçerse istek reddedilir. Böylece ölçüm “isteme hedef markayı enjekte ederek kendini anma” değil, sağlayıcının bilgi erişimi/yanıt üretimi davranışındaki organik görünürlüğü test eder.

01 / OPENAI

Responses API + Web Araması

OpenAI’nin web-search destekli API yüzeyi ölçülür. Son metin ve kaynak URL’ler marka/alan adı açısından kontrol edilir.

02 / PERPLEXITY

Sonar + Kaynak Gösterimleri

Sonar yanıtı, citations ve search_results birlikte incelenir; yalnız metin anılması ile alan adı kaynak gösterimi birbirinden ayrılır.

03 / GEMINI

Google Search Temellendirme

Gemini’nin Google Search temellendirme çıktısındaki yanıt metni ve temellendirme kaynak URL’leri ölçülür.

Tek ölçüm değil, zaman serisi.

Bu modülün ticari değeri aynı tarafsız istem setini düzenli aralıklarla tekrar çalıştırıp anılma/kaynak gösterimi değişimini göstermektir. API yüzeyleri ile son kullanıcı uygulama sonuçlarının aynı olmadığı açıkça raporlanır.
