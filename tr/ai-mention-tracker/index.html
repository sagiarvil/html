AI MENTION TRACKER / PAID MODULE

AI yanıtlarında markanız gerçekten geçiyor mu?

OpenAI Responses API + web search, Perplexity Sonar ve Gemini + Google Search grounding yüzeylerinde tarafsız sorguları çalıştırır; marka mention, domain citation ve kullanılan kaynak URL’lerini ayrı ölçer. Tüketici ChatGPT/Perplexity/Gemini arayüzleri birebir aynı sonuçları vermeyebilir.

AI görünürlüğünü kanıtla

Marka/domain yalnızca sonuçta aranır. Ölçüm sorgularına marka veya domain yazılması engellenir; aksi halde sonuç yapay biçimde yükselir.

Access key tarayıcıda kalıcı saklanmaz. Sağlayıcı API anahtarları yalnızca sunucu tarafında tutulur.
ÖLÇÜM SÖZLEŞMESİ

Markayı prompt’a yazıp “mention” üretmiyoruz.

Tracker’ın temel kuralı tarafsız sorgudur. Hedef marka veya domain sorguda geçerse istek reddedilir. Böylece ölçüm “prompt injection ile kendini anma” değil, sağlayıcının retrieval/generation davranışındaki organik görünürlüğü test eder.

01 / OPENAI

Responses + Web Search

OpenAI’nin web-search destekli API yüzeyi ölçülür. Son metin ve kaynak URL’ler marka/domain açısından kontrol edilir.

02 / PERPLEXITY

Sonar + Citations

Sonar yanıtı, citations ve search_results birlikte incelenir; yalnız metin mention ile domain citation birbirinden ayrılır.

03 / GEMINI

Google Search Grounding

Gemini’nin Google Search grounding çıktısındaki yanıt metni ve grounding source URL’leri ölçülür.

Tek ölçüm değil, zaman serisi.

Bu modülün ticari değeri aynı tarafsız prompt setini düzenli aralıklarla tekrar çalıştırıp mention/citation değişimini göstermektir. API yüzeyleri ile consumer uygulama sonuçlarının aynı olmadığı açıkça raporlanır.
