KAMUYA AÇIK METODOLOJİ

Her skorun izlenebilir bir nedeni olmalı.

Standart, vendor dokümanı, proposal, doğrudan ölçüm ve iç heuristik birbirine eşitmiş gibi sunulmaz. Ölçülemeyen sinyal pass veya fail olmaya zorlanmaz.

OFFICIAL_STANDARD

Normatif standart

Formal protokol veya platform standardı.

OFFICIAL_VENDOR

Birinci taraf vendor dokümanı

İlgili ürün veya crawler operatörünün güncel dokümanı.

PROPOSAL

Gelişmekte olan öneri

llms.txt gibi faydalı ancak zorunlu web standardı olmayan convention.

MEASURED

Doğrudan ölçüm

HTTP / HTML / header / robots / link evidence.

INTERNAL_HEURISTIC

Ürün heuristiği

Normatif güç iddiası olmadan decision-support kuralı.

EXPERIMENTAL

Deneysel yüzey

Düşük adoption / erken agent sinyali.

SCORING

UNKNOWN başarısızlık değildir. Başarı da değildir.

Reliable evidence yoksa kural denominator’dan çıkarılır. Core Web Vitals için field/lab veri yoksa NOT_MEASURED kalır.

SAFETY

SSRF fail-closed

Private/local/reserved hedefler, credential içeren URL’ler, non-standard portlar ve private ağa redirect pivotları reddedilir.
