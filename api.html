CI/CD kullanımı

Her deploy’da eşik kontrolü yapabilirsiniz.

GITHUB ACTIONSbash
body=$(curl -fsS https://htmlandhtml.com/api/scan \
  -H 'content-type: application/json' \
  --data '{"domain":"example.com","fresh":true}')
score=$(printf '%s' "$body" | jq -r '.overall')
[ "$score" -ge 80 ] || exit 1
