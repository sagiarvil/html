PRIVACY
PRIVACY / PUBLIC SCANS

Scan only what is public.

HTML&HTML's public scanner accepts a domain or public HTTP/HTTPS URL and measures externally visible responses. The scanner is not designed to receive credentials, private source code or authenticated application data.

DATA BOUNDARY

What the current application does.

This statement describes the current public validator implementation and should be updated if authentication, payment, analytics or persistent account storage is introduced.

INPUT

Public target

The scan request contains the domain/URL submitted to the public scan endpoint. Credential-bearing URLs, local/private/reserved targets and non-standard ports are rejected by the network safety boundary.

APPLICATION STORAGE

No scan database in the current code path

The current public scan endpoint processes the request and returns the result with Cache-Control: no-store. The application code path does not persist scan results to an application database.

INFRASTRUCTURE

Operational logs may exist

Hosting, CDN, DNS, security and network providers may process standard request metadata or operational logs under their own service controls. HTML&HTML does not claim that infrastructure produces zero logs.

SECRETS

Do not submit them

Do not provide passwords, cookies, authorization headers, tokens, payment data, personal data or private repository content to the public scanner.

EXTERNAL TARGETS

Public fetches are bounded

The scanner uses bounded HTTP requests, response-size limits, redirect limits, timeouts and DNS/private-address checks to reduce abuse and SSRF risk.

CHANGES

Policy follows product reality

If account storage, payment processing or additional telemetry becomes active, this page must be revised before those capabilities are represented as covered by this statement.

TÜRKÇE

Gizlilik sınırı

Mevcut public tarayıcı yalnızca girilen alan adı/URL ve herkese açık HTTP yüzeylerini işler. Public tarayıcıya şifre, token, cookie, ödeme bilgisi, kişisel veri veya özel kaynak kod gönderilmemelidir. Uygulama kodunda tarama sonuçlarını kalıcı uygulama veritabanına yazan bir akış bulunmaz; ancak hosting/CDN gibi altyapı sağlayıcılarında operasyonel loglar oluşabilir.
